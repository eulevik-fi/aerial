Windows screen saver that displays Apple aerial videos on multiple monitors.

* Run 'Setup Aerial' to configure the screen saver.
* While running, tap 'Shift' to enable captions.

The installer installs Aerial for all users under Program Files. Running 'Setup Aerial'
configures the screen saver for the current Windows account.

Download the latest installer from
https://github.com/eulevik-fi/aerial/releases
